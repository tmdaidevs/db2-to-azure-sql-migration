# Customer SSMA drop zone

Copy complete SSMA project folders below this directory. Do not edit report files after copying them.

Example:

```text
input/
└── CustomerProject/
    ├── *.db2ssproj
    ├── *.prefs
    ├── *.mb
    ├── *.mappings
    └── report/
        └── report_<timestamp>/
```

Keep separate schemas or SSMA projects in separate subfolders.
